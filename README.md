# Репозиторий для отчетов по лабораторным работам

В этом репозитории собраны отчеты и исходный код лабораторных работ по курсу глубокого обучения. На текущий момент здесь представлены материалы по первой и второй лабораторным работам.

> **Важно:** Все Jupyter-ноутбуки (`main.ipynb`) сохранены с уже выполненными ячейками, логами обучения, таблицами и графиками. Результаты можно просмотреть сразу в браузере без повторного запуска кода и переобучения моделей.

---

## Лабораторная работа №1 (Вариант №2)

Отчет и реализация многослойной полносвязной нейронной сети (FNN).
* **Путь до ноутбука:** `/lab1/main.ipynb`

### Цель работы
Построение, обучение и исследование полносвязной нейронной сети (Feed Forward Neural Network) для задачи многоклассовой классификации на табличных данных, а также сравнение её качества с классическим алгоритмом машинного обучения (логистической регрессией).

## Лабораторная работа №2 (Вариант №1)

Отчет и программная реализация свёрточных нейронных сетей (CNN) на примере архитектур **VGG** и **ResNet** для классификации изображений из датасета **CIFAR-10**.
* **Путь до ноутбука:** `/lab2/main.ipynb`

### Цель работы
Исследование операции двумерной свёртки, реализация с нуля и сравнение двух архитектур свёрточных нейронных сетей (**VGG** и **ResNet**) на задаче классификации цветных изображений (10 классов, 32×32), а также анализ проблемы переобучения и способов её устранения с помощью аугментации данных и планировщика скорости обучения.

### Структура проекта (`lab2`)
Вся логика вынесена в отдельные модули внутри папки `/lab2/src/`:
* `config.py` — конфигурация путей и гиперпараметров обучения (`seed`, `batch_size`, `learning_rate`, `epochs`).
* `dataset.py` — загрузка датасета CIFAR-10, перевод изображений в нормализованные тензоры на GPU и разбиение на выборки `train`, `val` и `test`.
* `models.py` — реализация классов архитектур `VGG` и `ResNet` (включая остаточный блок `ResNetBlock` со `Skip Connections`).
* `trainer.py` — цикл обучения и валидации, GPU-аугментация батчей на лету (`gpu_augment`), планировщик `CosineAnnealingLR` и сохранение лучших весов моделей.
* `metrics.py` — функции для построения графиков из JSON-логов, подсчёта числа параметров, расчёта метрик (`Accuracy`, `Precision`, `Recall`, `F1-score`) и отрисовки матриц ошибок (`Confusion Matrix`).
