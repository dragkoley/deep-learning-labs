##  Лабораторная работа №1 (Вариант №2)

В репозитории представлен отчет и программная реализация лабораторной работы по проектированию, обучению и исследованию многослойной полносвязной нейронной сети.

> **Важно:** Jupyter Notebook сохранен со всеми выведенными данными, логами обучения и графиками. Вы можете сразу приступить к **быстрому анализу результатов** без необходимости повторного запуска и обучения моделей.

---

### 🎯 Цель работы
Проектирование, реализация и исследование многослойной полносвязной нейронной сети (**Feed Forward Neural Network — FNN**) для решения задачи многоклассовой классификации на примере табличных данных. В ходе работы также проводится сравнительный анализ разработанной нейросети с классическим алгоритмом машинного обучения (Логистической регрессией).
